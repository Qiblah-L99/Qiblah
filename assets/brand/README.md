# Qiblah Brand Assets

These assets follow the current Qiblah moon-and-star direction: a filled gold crescent, a four point star, a round heavy wordmark, and a deep navy presentation background where needed.

- `qiblah-mark.svg` - transparent standalone crescent and star mark.
- `qiblah-logo-horizontal.svg` - transparent horizontal logo for headers and wider placements.
- `qiblah-logo-stacked.svg` - transparent stacked logo for centered layouts.
- `qiblah-logo-social.svg` - square navy logo lockup for profile images and social previews.

Core colors:

- Navy: `#061725`
- Gold light: `#FFE0A2`
- Gold mid: `#F2BE6D`
- Gold deep: `#C98435`
